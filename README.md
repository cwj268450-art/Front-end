# Calculator Frontend

前后端分离计算器系统 - 前端界面

## 项目介绍

这是软件工程实践第一次作业的前端部分，提供计算器的用户交互界面，包括按钮输入、表达式显示、结果展示和计算历史管理。

## 技术栈

- **HTML5** - 页面结构
- **CSS3** - 样式布局
- **JavaScript (ES6+)** - 交互逻辑和API调用

无需构建工具，纯静态页面。

## 运行环境

现代浏览器（Chrome / Firefox / Edge / Safari）

## 安装方法

无需安装，直接打开 `src/index.html` 即可。

或者使用简单的HTTP服务器：

```bash
cd src
python -m http.server 8080
```

然后访问 `http://localhost:8080`

## 前后端连接配置

前端默认连接后端地址为 `http://localhost:5000/api`。

如需修改后端地址，编辑 `src/index.html` 中的 `API_BASE` 变量：

```javascript
const API_BASE = 'http://localhost:5000/api';
```

## 功能说明

### 基本功能
- 数字输入（0-9）
- 四则运算（+ - × ÷）
- 括号支持
- 小数计算
- 一元正负号支持

### 计算历史
- 自动保存计算记录到后端数据库
- 展示历史记录（表达式、结果、时间）
- 删除单条历史记录
- 清空全部历史记录

### 错误处理
- 显示后端返回的错误信息
- 除零错误提示
- 无效表达式提示
- 服务器连接失败提示

## 设计说明

### 前后端分离架构
- 前端只负责UI展示和用户交互
- 所有计算逻辑都在后端完成
- 前端通过HTTP API与后端通信
- 历史数据存储在后端数据库，前端仅负责展示

### 界面布局
- 左侧：计算器主体（显示屏 + 按钮区）
- 右侧：计算历史面板（可滚动列表）
- 响应式设计，移动端自动上下排列
